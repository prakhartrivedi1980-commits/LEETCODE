## 📖 About

This repository is my personal **LeetCode problem-solving log**, where every solution is written in **C++** with a focus on clean logic, core data structures (Arrays, Linked Lists), and fundamental algorithmic techniques (Two Pointers, Math, Recursion, Greedy). It's a running record of practice aimed at strengthening problem-solving and interview-prep skills.

Each file is named after its corresponding **LeetCode problem number** (e.g. `1.cpp` → Problem #1: *Two Sum*), making it easy to look up, run, or reference any specific solution.

## ⚙️ How to Run

Each solution is a **self-contained C++ file**. To compile and test any solution locally:

```bash
# Clone the repository
git clone https://github.com/prakhartrivedi1980-commits/LEETCODE.git
cd LEETCODE

# Compile a specific solution (example: Two Sum)
g++ -std=c++17 -o solution 1.cpp

# Run it
./solution
```

> ℹ️ Some solutions (like `141.cpp` and `160.cpp`) build custom linked-list drivers for local testing since LeetCode's judge normally supplies the list structure — these are noted with an in-file comment.
